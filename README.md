# One Letter: Coffee or Tea

This entry is a deterministic Node 22 program that writes a single letter, A representing coffee, directly to entry.txt without any network access or external dependencies. Restricting the output to a solitary character distills the entire challenge down to pure minimalist efficiency and precision.

## How to Run

Execute the program using Node.js:

\`\`\`bash
node main.ts
\`\`\`

You can customize the target output directory by setting the `MAKEFUN_OUTPUT_DIR` environment variable:

\`\`\`bash
MAKEFUN_OUTPUT_DIR=./custom_output node main.ts
\`\`\`
